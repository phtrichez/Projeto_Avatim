# Catálogo Avatim

Interface Streamlit para consultar os produtos já coletados em `data/produtos_avatim.csv` e as descrições de fragrância em `data/fragrancias_avatim.csv`.

```powershell
pip install -r requirements.txt
streamlit run app.py
```

Use os filtros laterais para encontrar produtos por nome, código, linha, categoria oficial do catálogo, fragrância, perfil olfativo, disponibilidade e faixa de preço. A aba **Detalhe do produto** reúne imagem, preço, descrição, instruções de uso e, quando disponível, o texto “Sobre a fragrância”.
